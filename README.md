# \# 📋 CM Homepage Support Board Server

# 

# \## 🧱 프로젝트 개요

# CM이노베이션 홈페이지의 고객지원 게시판 서버입니다.  

# Node.js(Express) + MySQL 기반으로 게시글 CRUD 기능을 제공합니다.

# 

# ---

# 

# \## ⚙️ 기술 스택

# \- \*\*Backend\*\*: Node.js (Express)

# \- \*\*Database\*\*: MySQL 8.0  

# \- \*\*ORM/Driver\*\*: mysql2  

# \- \*\*환경 변수 관리\*\*: dotenv  

# \- \*\*CORS / JSON 파서\*\*: cors, express.json

# 

# ---

# 

# \## 🗂 폴더 구조

```server/

┣ config/

┃ ┗ db.js

┣ controllers/

┃ ┗ postController.js

┣ models/

┃ ┗ postModel.js

┣ routes/

┃ ┗ postRoutes.js

┣ server.js

┣ .env

┣ package.json

```
